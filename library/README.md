# Biblioteca de resultados

Índice de resultados técnicos revisados y útiles para el equipo. Cada resultado nuevo debe añadirse como una ficha Markdown breve en la carpeta temática correspondiente (por ejemplo, `core/`, `modesolver/`, `eme/` o `fdtd/`). Sigue las pautas de [`../CONTRIBUTING.md`](../CONTRIBUTING.md).

Las fichas resumen resultados de colaboración que también puedan consultar usuarios externos. Incluye propósito, conclusión, supuestos, límites, pasos de reproducción y ubicación de datos externos cuando aplique. `examples/` y `examples/notebooks/` son material educativo externo mantenido por Camilo, no el espacio de trabajo para producir estos resultados.

## Entradas

Todavía no hay resultados promovidos a esta biblioteca. El trabajo en curso se organiza en [`../work-in-progress/`](../work-in-progress/).
