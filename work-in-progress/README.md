# Trabajo en progreso

Este espacio contiene prototipos y notas temporales organizados por persona. Crea una carpeta con tu identificador estable (por ejemplo, usuario de GitHub) y copia [`_template/README.md`](./_template/README.md). Revisa [`../CONTRIBUTING.md`](../CONTRIBUTING.md) para el flujo de promoción a código, ejemplos, notebooks y biblioteca.

No guardes aquí credenciales ni archivos grandes de simulación. Mantén el contenido enfocado y retira los prototipos cuando se hayan promovido o descartado.
